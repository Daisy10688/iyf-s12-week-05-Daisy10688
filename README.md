# Week 5: DOM Manipulation

## Overview
This week focuses on understanding the Document Object Model (DOM) and using JavaScript to make web pages interactive.

## Topics Covered
- Selecting HTML elements.
- DOM traversal and navigation.
- Modifying HTML content and attributes.
- Creating and removing elements.
- Event listeners and user interactions.

## Mini Project: To-Do List Application

Built an interactive To-Do List using HTML, CSS and JavaScript.

**Features:**
- Add new tasks.
- Mark tasks as completed.
- Edit and delete tasks.
- Filter tasks (All, Active, Completed).
- Clear completed tasks.
- Display remaining tasks.

## Technologies Used
- HTML
- CSS
- JavaScript
